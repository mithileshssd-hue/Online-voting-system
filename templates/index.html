How It Works

A clear, verifiable 5-step voting process designed for fairness and transparency.

1
Login

Enter registered Voter ID in standard format.

2
Verify Identity

Complete simulated 4-digit OTP verification.

3
View Candidates

Review active candidates on the dynamic ballot.

4
Cast Vote

Select your candidate and review confirmation.

5
Recorded

Vote is saved atomically in SQLite database.

🛡️ Strict One-Vote Enforcement

Database transactions guarantee that each registered voter can submit exactly one ballot. Duplicate attempts are permanently blocked.

🔑 Cryptographic Hashing

Administrator passwords are encrypted using one-way SHA-256 cryptographic hashing. Plain text credentials are never stored.

📊 Real-Time Analytics

Votes are tallied mathematically via SQL queries, providing transparent turnout metrics and automatic leader/tie calculations.
